# ANC Dashboard — แดชบอร์ดงานฝากครรภ์ (HOSxP · นิยามตาม 43 แฟ้ม)

หน้า infographic เดียวโทนชมพู (รูปแบบเดียวกับ ER Dashboard) อ่านข้อมูลสดจาก HOSxP แบบอ่านอย่างเดียว
หน้าแดชบอร์ดแสดงเฉพาะจำนวนนับ — รายชื่อเบื้องหลังตัวเลขดูได้หลังเข้าสู่ระบบ (ดูด้านล่าง)
วิธีติดตั้งและ **ขั้นตอนตรวจก่อนใช้** ดู [INSTALL.md](INSTALL.md)

## หน้าจอ

1. ANC KPI Summary · 2. แนวโน้มรายเดือน · 3. ตัวชี้วัดคุณภาพ 10 ตัว (ผลงาน/เป้า/ผ่าน)
4. กลุ่มอายุ Teenage (< 20; ย่อย < 15, 15–19) · วัยเจริญพันธุ์ (20–34) · Elderly gravida (≥ 35) — อายุ ณ วันลงทะเบียนฝากครรภ์
5. แยกตาม รพ.สต. (ตำบล + หมู่ของแม่ ผ่าน `village_pcu.csv` แบบเดียวกับ mental_health_dashboard)
5b. คัดกรองครรภ์เสี่ยง 27 ข้อ (สมุดสีชมพู) แยก 4 หมวด · ผลลัพธ์แม่และทารก (ครรภ์เสี่ยง, คลอดก่อนกำหนด, ขาดออกซิเจน, ภาวะแทรกซ้อน)
6–9. Refer รายเดือน: กลุ่มอายุ · Top 10 Dx · ปลายทาง · ตารางเดือน × กลุ่ม Dx × ปลายทาง · 10. Alert & Action
หน้า `/check` = Data Audit · ปุ่มส่งออก JPG/PDF

## นิยามตัวชี้วัด (หน่วยนับ = ครรภ์)

**ข้อมูลบริการ** (การ์ดด้านบน ไม่ใช่ตัวชี้วัด): ฝากครรภ์รายใหม่ (`person_anc.anc_register_date` ในช่วง) ·
ครั้งบริการ ANC และเฉลี่ยต่อเดือน (`person_anc_service` ในช่วง)

ตัวชี้วัด 5 ตัวแรกตามเอกสารในโฟลเดอร์ `kpi/` (กรมอนามัย / HDC)

**ตัวหารในเขต (ค่าเริ่มต้น)** ตามเอกสาร KPI: หญิงไทย (`ANC_THAI_NATIONALITY`) ที่อาศัยในอำเภอ (`ANC_CHWPART`/`ANC_AMPPART`)
หรืออยู่นอกเขตแต่มาคลอดที่ รพ. (`person_anc.labour_hospcode` = `ANC_HOSPCODE`) · ปุ่ม "ตัวหาร: ทั้งหมด" = ทุกครรภ์ในทะเบียน
· ใช้กับ KPI ที่หารด้วยครรภ์ที่คลอด ส่วนข้อมูลบริการ ไอโอดีน (Workload) LBW และ refer นับทั้งหมด
· ถ้าบันทึกวันคลอดใน `person_anc` น้อยกว่า `ANC_LABOR_WARN_PCT` (80%) ของครรภ์ที่ครบกำหนด จะขึ้นเตือนบนแดชบอร์ด

## คัดกรองครรภ์เสี่ยง 27 ข้อ

ฟอร์มคัดกรองใน HOSxP (`person_anc_classifying_item`) มีแค่ 18 ข้อ จึงรวมหลายแหล่งต่อข้อ (ฐาน = ฝากครรภ์รายใหม่ในช่วง · ข้อเดียวถือเป็นครรภ์เสี่ยง)

| ที่มา | ใช้กับ | หมายเหตุ |
|---|---|---|
| F ฟอร์ม HOSxP | แท้ง, ทารกตาย, LBW, >4,000 g, ครรภ์เป็นพิษ, ผ่าตัด, แฝด, เลือดออก, เบาหวาน, หัวใจ, ไต | ติ๊ก `check_value='Y'` · ข้อ Rh/ก้อนในเชิงกราน/DBP>90/สารเสพติด/อายุรกรรมอื่น นับเข้า "มีความเสี่ยงอย่างน้อย 1 ข้อ" เท่านั้น |
| C คำนวณ | อายุ < 17 / ≥ 35, ส่วนสูง < 145, BMI < 18.5 / ≥ 25 | อายุคำนวณเอง (ช่องติ๊กอายุของฟอร์มสูงผิดปกติ) · ส่วนสูง/น้ำหนักจาก `opdscreen` ของ visit แรก (แทนน้ำหนักก่อนท้อง) |
| D Dx ICD-10 | โรคเรื้อรัง, ติดเชื้อ, ไทรอยด์, จิตเวช, SLE, แฝด, รกเกาะต่ำ ฯลฯ | `ovstdiag` + `iptdiag` · รหัสหมวด O นับตั้งแต่ LMP · โรคเรื้อรังย้อนหลังได้ |
| T ข้อความ HPI/PMH | คลอดก่อนกำหนด, ท้องนอกมดลูก, ตกเลือดหลังคลอด, พิการแต่กำเนิด ฯลฯ | **ประมาณการ** · regex ตัดประโยคที่ขึ้นต้น ปฏิเสธ/ไม่เคย/ไม่มี/denied/no ออกก่อน · โรคประจำตัวค้นเฉพาะ PMH, ประวัติอดีตค้น HPI+PMH, ภาวะปัจจุบันค้น HPI |

รหัส Dx, regex และเกณฑ์ตั้งได้ด้วย `ANC_RISK_DX_<ข้อ>` · `ANC_RISK_TEXT_<ข้อ>` · `ANC_RISK_AGE_LOW/HIGH` · `ANC_RISK_HEIGHT_CM` · `ANC_RISK_BMI_LOW/HIGH`
(ชื่อข้อดูใน `risk27.py`) · หน้า `/check` แสดงจำนวนที่พบรายข้อและรายแหล่ง · แสดงเฉพาะจำนวนนับ ไม่มีข้อความ HPI หรือข้อมูลรายคนออกจากระบบ

ตัวหาร 0 แสดง “—” · ตัวหาร < 5 แสดงจาง (ฐานน้อย ตีความระวัง) · ค่าทุกตัวตั้งได้ใน `.env` (ดู `.env.example`)

## รายชื่อและส่งออก Excel (ต้องเข้าสู่ระบบ)

ตัวเลขเกือบทุกช่องบนแดชบอร์ดกดได้ → หน้า `/list` แสดงรายชื่อเบื้องหลังตัวเลขนั้น (แบบ mental_health_dashboard)

- **อัตรา** (≤12 wk, ครบ 5/8 ครั้ง, dT, โลหิตจาง ฯลฯ) แสดงทั้งตัวหาร มีคอลัมน์เข้าเกณฑ์ ✔/✘ และปุ่มกรอง
  “เฉพาะไม่เข้าเกณฑ์” ไว้ติดตาม · ANC ครบ 5/8 ครั้งบอก **ช่วงอายุครรภ์ที่ยังขาด**
- ตาราง รพ.สต. / กลุ่มอายุ / ครรภ์เสี่ยง 27 ข้อ / ผลลัพธ์ / refer กดได้ทุกช่อง · ทารก (LBW, ขาดออกซิเจน, ตายคลอด, BBA) แสดงเป็นชื่อมารดา
- ค้นชื่อ/HN · ส่งออก Excel ตามตัวกรองที่ใช้อยู่ หรือแยกชีทตาม รพ.สต.
- รายชื่อใช้เงื่อนไขชุดเดียวกับตัวเลข (`drill.py` เรียกฟังก์ชันใน `metrics.py` / `risk27.py`) และ `tests/test_drill.py`
  ตรวจว่าจำนวนแถวเท่ากับตัวเลขบนแดชบอร์ดทุกช่อง

ความปลอดภัย: บัญชีรายคน (`python manage.py adduser ...`) รหัสผ่าน pbkdf2:sha256 · ผูกบัญชีกับ รพ.สต. ได้ (เห็นเฉพาะเขตตัวเอง)
· ล็อกชั่วคราวเมื่อใส่รหัสผิดซ้ำ · CSRF · บันทึกทุกการเข้าสู่ระบบ/เปิดดู/ส่งออก (`python manage.py audit`)
· ไม่ตั้ง `ANC_SECRET_KEY` = ปิดหน้ารายชื่อทั้งหมด · `ANC_LIST_LAN_ONLY=1` = เปิดได้เฉพาะใน รพ.
· โหมดพิมพ์/ไฟล์ส่งออก JPG/PDF และ `/api/data.json` ยังไม่มีชื่อผู้ป่วย

## พัฒนา

```bash
pip install -r requirements-dev.txt
python -m pytest -q
python app.py            # http://127.0.0.1:6300/
python render.py --fmt jpg
python build_dist.py     # dist/anc_dashboard-<version>.zip
```

โครงสร้าง: `queries.py` ดึงแถวระดับครรภ์/visit/ทารก/refer · `metrics.py` คำนวณทุกตัวเลข (ไม่แตะฐานข้อมูล ทดสอบได้)
· `check.py` Data Audit · `config.py` ค่าตั้ง · `app.py` หน้าเว็บ · `drill.py` รายชื่อเบื้องหลังตัวเลข
· `listing.py` ตารางรายชื่อ/Excel · `store.py` + `manage.py` บัญชีผู้ใช้และ audit log (SQLite ใน `data/`) · spec/แผนอยู่ใน `docs/superpowers/`
